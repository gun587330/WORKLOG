# WORK LOG 디자인 시스템 (DESIGN)

> anserx-code `docs/frontend/DESIGN.md` 의 결정과 근거를 그대로 가져오고, 색만 블랙 계열로 바꿨다. 토큰 값의 단일 소스는
> `web/src/styles/theme.css`, 이 문서는 **왜 그렇게 정했는지와 하지 말아야 할 것**을 남긴다. (최종 수정: 2026-10-21)

## 0. 원칙 3줄

1. **주제에서 디자인을 끌어낸다.** 매일 읽는 기록 지면이다. 장식이 아니라 읽힘이 기준이다.
2. **플레이스홀더 금지.** 빈 자리를 그라디언트 박스로 때우지 않는다.
3. **AI 기본값 회피.** 임의 그라디언트 · 이모지 섹션 마커 · 발명한 색 · 새로 지어낸 카드/버튼 스타일 금지. 토큰과 공용 컴포넌트만.

## 1. 색 — 블랙 · 다크 그레이 (2026-10-21 확정, 안 A)

| 토큰 | 값 | 용도 |
|---|---|---|
| `--accent` | `#1f1d24` | primary. 버튼 · 링크 · 활성 칩 글자 · 타임라인 마커 |
| `--accent-2` | `#000000` | hover |
| `--accent-soft` | `#4a4756` | 배지 · 아바타 그라디언트 · 달력 "진행" 바 |
| `--accent-tint` | `#ececf0` | 활성 칩 배경 · 인용 배경 |
| `--paper` / `--bg-soft` | `#ffffff` / `#f4f4f6` | 지면 / 연회색 면 |
| `--ink` / `--ink-2` / `--line` | `#16151c` / `#6b6b75` / `#e6e6eb` | 본문 / 보조 / 선 (보라 기운 없는 회색) |
| `--pass` / `--caution` / `--block` | `#0e7c5a` / `#b26a00` / `#c4142e` | 완료 / 진행 중 / 삭제 (ANSERX 그대로) |
| `--plan-bar` / `--done-bar` | `#d99a06` / `#4a4756` | 달력 항목 색 바: 계획된 작업 / 진행한 프로젝트 |
| 다크 `--accent` | `#e6e6ea`, `--accent-tint #2a2a30` | |

> 타임라인 마커 삼각형은 CSS `data:` SVG 안에 색이 박혀 있어 토큰을 못 쓴다. 값은 `--accent` 와 같은 `#1f1d24`, 진행 중은 `--caution`. 토큰을 바꾸면 여기도 같이 바꾼다.

## 2. 타이포그래피 · 치수

- 폰트 스택 · Pretendard 로딩 · rem 전용 + 루트 유동 스케일(`html { font-size: clamp(1rem, calc(1rem + (100vw - 90rem) / 280), 1.25rem) }`)은 ANSERX 와 같다. px 는 `1px` 헤어라인과 `@media` 만 허용.
- 좌측 네브바 폭 `9.5rem`(ANSERX 11.625rem 보다 좁게). 접으면 완전히 사라지고 좌상단 펼침 버튼만 남는다.

## 3. 표면 — 작업 공유 표면이 이 사이트의 기본

ANSERX 에서는 작업 공유 페이지에 한정했던 **토스식 평면 표면**(연회색 워시 위 테두리 없는 흰 면 + 큰 라운드 + 넉넉한 여백, 표는 행 구분선만, 칩 · 토글은 연회색 면)이 여기서는 **모든 화면의 기본**이다. 유리 카드(`ui/glass-card`)는 쓰지 않는다(모달 · 네브바도 평면).
- 화면 안의 항목 카드(기록 카드 · 프롬프트 카드 · 목표 행)는 `--bg-soft` 면, 테두리 없음. 호버 = 살짝 떠오름 + 음영.
- 박스마다 **바닥 푸터**(`.cfoot`)에 그 박스의 안내 한 줄. 스크롤 영역 밖에 고정.
- 추가 · 수정은 전부 모달 폼(`ui/modal` size lg, 네브바를 뺀 영역 가운데). 삭제는 확인 모달 + `variant="danger"`.

## 4. 컴포넌트 (ANSERX 원본 그대로)

버튼 `ui/button`(cta · secondary · danger, 유리 버튼 금지 · `check:glass` 강제) · 칩 `ui/chip`(토글 · 정적 · 상태 톤) · 입력 `ui/field` `ui/textarea` `ui/segmented` · 모달 `ui/modal` · 페이저 `ui/pager` · 스켈레톤 · 토스트 · 아이콘 오버레이 버튼(삭제 색 원본) · 뒤로가기 `common/back-link`.

## 5. 화면별 결정 (가안 v11, 2026-10-21)

- 홈: 1행 KPI 타일 3 + 이번 주 투입(순위 · 배지 · 시간), 2행 달력(애플식 항목 행, `+N`, 흰 카드 말풍선이 박스 밖으로) + 앞으로 할 일(사각 체크) + 진행 중인 계획. 서브 제목 없음.
- 작업 기록: 프롬프트 스트립(가로 드래그) + 기록 1행(가로 드래그, 카드 높이는 남는 공간, 폭 `clamp(18rem, 26vw, 24rem)`). "새 기록 올리기" 는 기록 박스 머리 우측.
- 계획 · 목표: 좌 계획 목록 / 우 목표 평면 목록(제목 옆 프로젝트 배지).
- 그래프는 전부 `brand/kpi-tile` 계보의 면 스파크라인 + 호버 말풍선.

## 6. 금지

유리 버튼 · 임의 색 · px 치수 · 이모지 · 긴 대시 · 카드 안 설명문(푸터로) · 인라인 추가 폼.

## 알림(토스트) 방식 (2026-10-21 결정)

- 사이트의 **모든 알림은 `ui/toast` 하나**로 띄운다. 저장 · 삭제 · 복사 결과뿐 아니라 로그인 실패(이메일 · 비밀번호 오류)처럼 폼 오류도
  인라인 빨간 글 대신 토스트다. 인라인으로 남는 것은 "상태"(불러오기 실패 안내, 검수 문제 목록)뿐이다.
- 위치는 **좌측 상단**. ANSERX 는 우측 상단이지만 WORK LOG 는 좌측 네브바 바로 오른쪽(`left: var(--sidebar-w)`)에 둔다. 모바일은 왼쪽 끝.
- 모양은 ANSERX 와 같다(불투명 흰 카드 + 그림자, 제목 색 하나로 강조: 기본 `--ink` · 성공 `--pass` · 실패 `--block`). 그림자 토큰
  `--glass-shadow` 의 보라 기운을 중립(rgba 20,20,28)으로 바꿨다.
